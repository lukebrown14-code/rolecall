# Full Stack Engineer — Bluegum Health

Melbourne (hybrid) · Permanent

full stack engineer to work across our Python APIs and React front end.

- Build features end to end, from PostgreSQL schema to React screens.
- Keep our Django services fast and well tested.
- Help clinics move off their old booking systems.

## You have

- Python and Django in production.
- React and TypeScript.
- PostgreSQL.
- A habit of writing integration tests.
