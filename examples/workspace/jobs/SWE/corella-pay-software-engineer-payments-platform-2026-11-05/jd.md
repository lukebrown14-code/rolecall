# Software Engineer, Payments Platform — Corella Pay

Melbourne (hybrid) · Permanent · $155,000 – $175,000 plus super

Corella Pay processes card and account-to-account payments for 3,000 Australian small
businesses. The Payments Platform team owns the services that authorise, settle and reconcile
every transaction.

## The role

- Build and run Go services that handle payment authorisation and settlement.
- Keep the settlement pipeline observable and fast to recover when a bank feed fails.
- Improve the deploy pipeline so changes reach production safely several times a day.
- Join the on-call rotation and help write the runbooks.

## About you

- Experience building backend services in Go or Python.
- Strong PostgreSQL and REST API design.
- Docker, Terraform and AWS.
- CI/CD with GitHub Actions or similar.
- Calm on call, and keen to make incidents rarer.
