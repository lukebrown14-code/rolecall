# Backend Developer — Wattlebird Games

Melbourne (Collingwood) · Permanent

Wattlebird Games makes mobile puzzle games played by two million people a month. We need a
backend developer for the services behind accounts, leaderboards and in-game events.

## You will

- Build Go and Python services for player accounts and leaderboards.
- Run them on AWS with Docker and Terraform.
- Keep them fast during weekend event spikes.

## You have

- Backend services in Go or Python.
- PostgreSQL and Redis.
- AWS.
