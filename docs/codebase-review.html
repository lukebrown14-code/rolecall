Highest-impact improvements

  1. Clamp cursor on every Update exit + one selected() accessor — fixes the panic (model.go, detail.go, view.go).
  2. Render only visible rows — compute block heights, drop the double build; ~90% of a 10 ms frame (view.go:619).
  3. Unify key dispatch & help into one table so b/f/p gating can't drift (model.go vs help.go).
  4. Delete init's config writer and call config.Patch (init.go:236).
  5. One workspace.json reader + one schema guard across store (reads/settings/tracks).
  6. One pass TrackCounts() replacing N full-tree walks per Settings load.
  7. Cache doc/detail/profile renders, invalidated by the watch — stops 3× Glamour renders per frame.

Quick wins (low risk)

  1. Enable errcheck + staticcheck + unused and lower dupl to ~60 (.golangci.yml).
  2. Skip .git in the doctor walk + regression test.
  3. Delete dead code: RenderColumns, boxed() ×11, unused constants/fields.
  4. One Python Workspace seam — resolve(args.data), delete the 7 hand-rolled --data flags.
  5. Hoist shared test helpers (36× os.CopyFS, 9 harnesses) into helpers_test.go.
  6. Derive one card body for detail card + preview.
  7. Document roles.json / sweep-candidates.md in SCHEMA.md.
